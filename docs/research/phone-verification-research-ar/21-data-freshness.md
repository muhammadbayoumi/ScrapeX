# 21 — عمر النتيجة وإعادة الفحص

## السؤال

كم تظل كل نتيجة صالحة، ومتى نعيد الفحص؟

## لماذا تختلف مدة الصلاحية؟

بعض البيانات شبه ثابتة مثل صيغة الدولة، وبعضها يتغير سريعًا مثل Line Status أو الشبكة الحالية أو SIM Swap. وضع TTL واحد لكل النتائج يخلق قاعدة بيانات تبدو دقيقة وهي قديمة.

## مدد ابتدائية مقترحة

هذه قيم تشغيلية أولية تُعاير بعد التجربة، وليست حقائق ثابتة:

| الدليل | مدة أولية قبل اعتباره Stale |
|---|---:|
| التنسيق وE.164 | يعاد عند تغير خوارزمية التطبيع |
| صلاحية metadata والنوع المبدئي | 90 يومًا أو عند تحديث المكتبة |
| الشركة الأصلية | 180 يومًا أو عند تحديث metadata |
| الشركة الحالية وPorting | 7–30 يومًا حسب أهمية الرقم |
| Line Status | 24 ساعة–7 أيام حسب الاستخدام |
| وجود واتساب | 7–30 يومًا مع تقليل الاستعلامات |
| Caller labels | 30–90 يومًا |
| الهوية التجارية من الموقع | عند إعادة Crawl أو بعد 30–90 يومًا |
| Spam/Scam risk | 1–7 أيام للحالات المهمة |
| Reassigned Number | قبل استخدام موافقة قديمة أو بعد انقطاع طويل |
| SIM Swap | وقت العملية الحساسة فقط |
| Ownership Verification | مرتبط بالجلسة أو العملية، وليس دائمًا |
| Consent | حتى السحب أو انتهاء الغرض، مع مراجعة القواعد المطبقة |

## منطق إعادة الفحص

- لا نعيد كل الطبقات معًا.
- نعيد فقط الدليل المنتهي أو المطلوب للقرار الحالي.
- الأحداث المهمة، مثل فشل رسالة أو ظهور اسم جديد أو تغير Carrier، قد تبطل أدلة مرتبطة.
- نستخدم Cache مشتركًا لتجنب دفع التكلفة أو الضغط على الخدمات مرتين.
- الأرقام الأكثر استخدامًا تحصل على تحديث أقرب، والبيانات الأرشيفية أقل تكرارًا.

## النتيجة المقترحة

```text
evidence_id
evidence_type
observed_at
valid_until
freshness_status: fresh | stale | expired | event_invalidated
provider_version
source_version
refresh_reason
```

## علاقات الإبطال

- Reassigned Number جديد يبطل الاسم والموافقة والملكية القديمة.
- SIM Swap حديث لا يبطل ملكية الرقم تلقائيًا، لكنه يرفع الحاجة لإعادة التحقق.
- Porting يبطل Current Carrier القديم، ولا يبطل الرقم.
- تحديث libphonenumber قد يغير صلاحية النمط أو نوعه.
- إزالة الرقم من الموقع الرسمي تجعل Business Match قديمًا لا محذوفًا فورًا.

## التوصية

نبني سجل Evidence غير قابل للاستبدال، ثم نحسب أحدث حالة من الأدلة السارية. لا نكتب فوق النتيجة القديمة؛ نحتفظ بالتاريخ لمعرفة لماذا تغير القرار.
