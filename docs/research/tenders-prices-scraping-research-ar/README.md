## الإجابة المختصرة

نعم، توجد أنظمة ومصادر لتتبّع المناقصات وطرح المشروعات، لكن لا توجد قاعدة مفتوحة واحدة تغطي العالم كله. الأفضل هو دمج المصادر الرسمية المنظمة أولًا، ثم استخدام scraping للمصادر التي لا توفر API أو ملفات تنزيل.

نعم، يمكن تتبّع أسعار المنتجات. توجد أدوات مفتوحة جاهزة للمراقبة والتنبيه، لكن المقارنة الصحيحة تتطلب التأكد أن النتائج تخص **نفس المنتج ونفس النسخة والكمية والبائع والبلد**.

أما scraping فليس App واحدًا؛ هو طبقة مشتركة تحتوي محركات HTTP ومتصفحات وتتبّع تغييرات واستخراج ملفات وجدولة ومراقبة جودة.

## كيف ترتبط بالمنظومة السابقة؟

```text
Company Enrichment
  ├─ منتجات الشركة + صناعتها + الدول المستهدفة
  │              ↓
  │        Tender Matching App
  │              ↓
  │  فرص مناسبة + مشترون + فائزون سابقون
  │
  └─ نطاقات ومتاجر ومنتجات
                 ↓
          Price Tracking App
                 ↓
      أسعار + مخزون + عروض + تاريخ

Scraping Platform = طبقة الجمع المشتركة عند غياب API/Feed
```

يمكن لمنظومة البريد والهاتف وإثراء الشركات دعم المناقصات ببيانات المورد والمشتري، لكن لا يجب خلط البيانات الشخصية تلقائيًا بسجل فرصة عامة.

## قاعدة اختيار طريقة الجمع

```text
1. API رسمي أو ملف bulk
2. معيار مفتوح مثل OCDS / JSON-LD
3. RSS / Atom / sitemap / CSV / XML
4. HTTP + HTML ثابت
5. متصفح آلي للـJavaScript عند الضرورة
6. مراجعة يدوية للمصدر المحمي أو غير المسموح بأتمتته
```

المتصفح الآلي أبطأ وأغلى وأكثر هشاشة؛ لا يُستخدم لمجرد أنه متاح.

## التكلفة بصورة عملية

| بند | MVP شخصي | عند التوسع |
|---|---|---|
| تراخيص الأدوات المفتوحة | غالبًا صفر | راجع AGPL وشروط كل مشروع |
| APIs الحكومية المفتوحة | غالبًا صفر مع حصة/مفتاح | صيانة الموصلات والحصص |
| خادم وتخزين | صغير عند عدد محدود من المصادر | يزيد مع المتصفحات والملفات والتاريخ |
| Proxies/CAPTCHA | لا تُفترض حاجة إليها | لا تستخدمها لتجاوز منع أو وصول غير مصرح |
| LLM/embeddings | اختيارية للمطابقة والتلخيص | تكلفة حسب الحجم؛ القواعد التقليدية أولًا |
| صيانة | أهم تكلفة حقيقية | تغيّر المواقع والحقول يحتاج اختبارات وإصلاحًا |

لا يمكن وضع رقم نهائي قبل معرفة عدد المصادر والمنتجات ودورية التحديث ونسبة الصفحات التي تحتاج متصفحًا. التصميم هنا يبقي كل موصل منفصلًا كي يمكن استبداله دون تعديل المنظومة كلها.

## قواعد الجودة والالتزام

- «لم نجد» لا تعني «غير موجود».
- خزّن رابط المصدر ووقت الجمع والنسخة الخام أو بصمتها وطريقة الاستخراج.
- راجع ترخيص **البيانات** وشروط الموقع، لا ترخيص أداة scraping فقط.
- احترم [Robots Exclusion Protocol](https://www.rfc-editor.org/rfc/rfc9309.html) والحصص ومعدل الطلبات.
- لا تتجاوز login أو CAPTCHA أو حجبًا تقنيًا للوصول إلى بيانات غير مصرح بها.
- افصل إشارات المخاطر عن الاستنتاجات؛ red flag ليست إثبات مخالفة.
- أجّل قرار المكتبات النهائية والتكامل مع الأداة الحالية إلى فحص الريبو والبنية الفعلية وقت التنفيذ.
