# 03 — النسخ والعبوات وسعر الوحدة

## المشكلة

السعر يتغير حسب اللون، المقاس، السعة، الوزن، pack، الاشتراك أو الحالة. السعر الأقل قد يخص variant غير المحدد أو عبوة أصغر.

## الحقول

`variant_attributes`, `quantity`, `unit`, `pack_count`, `net_content`, `condition`, `subscription`, و`selected_variant_evidence`.

## التطبيع

احسب سعر الوحدة فقط عندما تتوافق الوحدات: SAR/kg، SAR/L، SAR/item أو SAR/GB مثلًا. احتفظ بالسعر الأصلي وصيغة التحويل. لا تحول بين الوزن والحجم دون كثافة معلومة.

## الاستخراج

قد تكون variants في JSON-LD، JSON داخل الصفحة، API داخلي مشروع ومسموح، أو تفاعل browser. عند URL واحد لعدة خيارات يجب تثبيت الخيار قبل تسجيل السعر والتقاط هويته.

## قواعد

- `pack of 6 × 330ml` لا يساوي `6ml` ولا `330ml` منفردًا.
- المنتج refurbished/used كعرض منفصل.
- سعر subscription ليس regular price.
- إذا لم تُعرف النسخة، النتيجة `variant_unknown` ولا تدخل مقارنة تلقائية.

**الناتج:** مقارنة على مستوى النسخة وسعر وحدة قابل للتفسير.
