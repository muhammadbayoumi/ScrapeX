# 09 — سجل الأسعار والتغييرات والتنبيهات

## التخزين الصحيح

احتفظ بلقطات append-only بدل استبدال السعر القديم: `observed_at`، السعر، العملة، التوفر، البائع، الموقع، نوع العرض، رابط المصدر، hash للدليل وإصدار parser. ثم اشتق أحداثًا مثل: انخفاض، ارتفاع، بدء/انتهاء عرض، عودة للمخزون، اختفاء العرض، أو فشل الاستخراج.

## التنبيهات

- سعر أقل من هدف.
- انخفاض بنسبة أو قيمة محددة.
- أفضل سعر بين بائعين بعد الشحن.
- عودة مخزون أو تغير حالة التوصيل.
- انتهاء صلاحية البيانات `TTL` أو تعطل extractor.

تمنع طبقة dedup تكرار نفس التنبيه، وتستخدم فترة تهدئة حتى لا تتحول التقلبات القصيرة إلى ضوضاء. فشل parser ليس «نفاد مخزون» ولا «سعر صفر».

## مشروعات جاهزة

[changedetection.io](https://github.com/dgtlmoon/changedetection.io) مناسب لمراقبة صفحات وأسعار وتوفر مع API وتنبيهات، و[urlwatch](https://github.com/thp/urlwatch) خفيف لمقارنة HTML/JSON بعد تطبيق filters، و[Huginn](https://github.com/huginn/huginn) يبني workflows أوسع. يمكن تشغيل أكثر من App: مراقب سريع للروابط الفردية، ومتعقب كتالوج يحتفظ بتاريخ منظم.
