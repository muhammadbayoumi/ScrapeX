# 01 — اختيار المصدر: API أولًا

## ترتيب الاختيار

1. API أو feed رسمي موثق.
2. JSON-LD أو JSON مضمّن أو HTML ثابت.
3. متصفح JavaScript عند غياب بديل ثابت.
4. PDF/OCR عندما تكون الوثيقة هي المصدر.
5. LLM extraction كمساعد لا كمصدر للحقيقة.

الـAPI أقل استهلاكًا وأكثر ثباتًا، لكنه لا يعني استخدامًا بلا حدود؛ نسجل المصادقة والحصص والترخيص وشروط إعادة الاستخدام وpagination وأوقات التحديث.

## سجل المصدر

نحفظ المالك، النوع، النطاق المسموح، المنطقة واللغة، معدل الطلبات، robots.txt والشروط، schema المتوقع، extractor وإصداره، تاريخ آخر نجاح، ومدة صلاحية البيانات. بذلك تستخدم تطبيقات المناقصات والأسعار والشركات طبقة الجلب نفسها.

## معيار القرار

نختار أقل مسار يجلب الحقول المطلوبة. قبل إضافة المصدر ننفذ عينة صغيرة ونقيس الاكتمال والتغير والتكلفة، ثم نقرر الجدولة.
