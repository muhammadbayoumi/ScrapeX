# 03 — JavaScript والمتصفح

[Playwright](https://github.com/microsoft/playwright) هو الاختيار الافتراضي للصفحات الديناميكية، مع [Selenium](https://github.com/SeleniumHQ/selenium) للـWebDriver متعدد اللغات و[Puppeteer](https://github.com/puppeteer/puppeteer) لمشروعات Node. ويمكن لـ[Crawlee](https://github.com/apify/crawlee) إدارة الطوابير والجلسات حول المتصفح.

انتظر selector أو response محددًا بدل وقت أعمى، وامنع الموارد غير اللازمة، وضع timeout وmemory limit، وأعد تدوير contexts. افصل browser workers الثقيلة عن HTTP workers، واحفظ screenshot/HTML عند الفشل وفق سياسة الخصوصية.

المتصفح fallback مكلف وهش. التفاعل قرائي: لا شراء ولا إرسال نموذج ولا تغيير حساب. لا نتجاوز CAPTCHA أو الحجب؛ جلسة المستخدم المصرح بها سر منفصل لكل مصدر.
