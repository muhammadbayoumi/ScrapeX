# 06 — استخراج النص وLLM

[Trafilatura](https://github.com/adbar/trafilatura) مناسب لتنظيف نص المقالات والصفحات، بينما [Crawl4AI](https://github.com/unclecode/crawl4ai) و[Firecrawl](https://github.com/firecrawl/firecrawl) ينتجان Markdown/JSON ملائمين للمعالجة. راجع ترخيص Firecrawl وفروق self-hosting عن الخدمة السحابية، وثبت إصدارات Crawl4AI الحديثة واعزل الخدمة.

## مكان LLM

يستخدم LLM لاستخراج حقول من نص غير منتظم أو تصنيف المحتوى بعد فشل القواعد الحتمية، وليس لتخمين بيانات غير موجودة. يُطلب منه إعادة schema محدد، ثم تمر النتيجة على validator. كل حقل يحتفظ بمقتطف دليل وموقعه؛ لا تُقبل نتيجة بلا دليل.

التكلفة تتغير بطول المحتوى وعدد المحاولات. لذلك ننظف النص ونقسمه ونرسل الأجزاء المحتملة فقط، ونخزن النتيجة حسب hash. البيانات الحساسة لا ترسل إلى خدمة خارجية دون تفويض وسياسة واضحة.
