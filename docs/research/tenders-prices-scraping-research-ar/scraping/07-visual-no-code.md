# 07 — الأدوات المرئية وNo-code

لا يظهر مشروع مفتوح ناضج يطابق كل وظائف المنتجات التجارية المرئية مثل Octoparse أو ParseHub. الأقرب حسب المهمة: واجهة [changedetection.io](https://github.com/dgtlmoon/changedetection.io) لتحديد أجزاء ومراقبتها، [Crawlab](https://github.com/crawlab-team/crawlab) لإدارة spiders، و[AutoScraper](https://github.com/alirezamika/autoscraper) لاستنتاج قواعد بسيطة من أمثلة.

## الأنسب لمنظومتك

ابنِ App إعداد غير تقني فوق المحركات الموجودة: يختار المستخدم نوع المصدر، URL، مثال الحقل، الجدولة والتنبيه. في الخلفية ينشئ النظام Source Profile وselectors قابلة للاختبار، لا كودًا غير مرئي يصعب صيانته.

معاينة النتيجة، تمييز الحقول المفقودة، واختبار عدة صفحات قبل الحفظ أهم من السحب والإفلات نفسه. القاعدة المستنتجة لا تدخل الإنتاج قبل fixture tests ومراجعة عينة.
