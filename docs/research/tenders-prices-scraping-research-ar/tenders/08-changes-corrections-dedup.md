# 08 — التعديلات والإلغاء وإزالة التكرار

## المشكلات

نفس الفرصة قد تظهر في منصة وطنية وTED، أو تنشر كإعلان وتعديل وتمديد وترسية. الاعتماد على URL أو العنوان يولد تكرارًا أو يفقد التغييرات.

## مفاتيح الربط

`ocid` إن وجد، رقم notice/procedure الرسمي، buyer ID، lot، العنوان، التاريخ والمرجع المتقاطع. استخدم exact IDs أولًا ثم fuzzy matching للمراجعة.

## نموذج versions

لا تكتب فوق السجل. خزّن snapshot أو release لكل مشاهدة، ثم احسب diff دلاليًا على الحقول:

- موعد جديد.
- قيمة أو lot تغير.
- مستند مضاف/استبدل.
- سؤال/إجابة أو corrigendum.
- status: cancelled/awarded/unsuccessful.

## أدوات

[OCDS Kit](https://github.com/open-contracting/ocdskit) يستطيع compile/version/merge لحزم OCDS. للمصادر غير المنظمة تستخدم hash وفروق الحقول والنص، ويمكن الاستفادة من changedetection.io/urlwatch للاكتشاف لا كنموذج بيانات نهائي.

## قواعد

إعادة ترتيب HTML أو تغيير عداد الصفحة ليس حدث مناقصة. أنشئ تنبيهًا فقط بعد normalization، واحتفظ بسبب الدمج كي يمكن فصل سجلات دُمجت خطأ.
