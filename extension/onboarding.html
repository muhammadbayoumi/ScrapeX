Welcome to ScrapeX

A scraping tool that runs entirely on your machine. The extension is the interface — the engine is a small local app you install once.

Checking for the ScrapeX engine…
1

Download ScrapeX-Engine

Open the Engine page in the ScrapeX panel and press the download button. It hands you a single file, scrapex-engine.exe — there is nothing to install first, and no terminal is involved.

2

Run it once

Double-click the file. It installs for you alone and asks for no administrator rights.

Windows will warn once that the publisher is unknown, because the file is not code-signed. Choose More info, then Run anyway. The Engine page shows a checksum if you want to prove the download arrived whole.

3

Come back here

Leave the engine's window open — that window is the engine. This page notices it by itself within a few seconds; there is nothing to press.

That button asks Chrome to start the engine for you, so the window stops being needed. If Chrome says it cannot find it, the one-time link-up is in the panel's Setup section.
