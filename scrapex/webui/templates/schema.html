Schema

What every column is, where it appears, and which sources actually fill it. Read from the code and the warehouse, not written by hand, so this page and the table can never disagree.

The two places

The table answers “how do these compare?” — what you scan across many rows and sort, filter or group by.

The container underneath answers “what is this one thing?” — pictures, description, specifications, attachments and the price story. It opens when you select a row; select two or more and it compares them instead.

Move any field between the two with Choose Columns: hiding a field moves it into the container rather than losing it.

The rules

  1. A column's name states the language of its content, in display and in storage. English is primary, so an unmarked name is English and Arabic is marked (AR).
  2. One language at a time. The AR|EN switch governs the table and the container together.
  3. A missing translation shows the fact, never a blank.
  4. Presence is per source. A column appears only where that source's own rows fill it.
  5. Nothing is computed into a price. Every figure is what the source published; the Tax column states, per row, whether it includes tax.

Classification splits into as many as {{ schema.category_levels }} levels; each level appears only for sources that actually reach that depth.
